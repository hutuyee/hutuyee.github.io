关于文档 ​

这里放的是我几个 Minecraft 插件的使用说明：ShitBot、BiliMusicBridge，以及 AllMusic 的 QQ 音乐和酷狗音乐源。装哪个插件，就从对应的安装页开始看。配置、命令和常见问题也都放在各自的目录里。

文档与版本 ​

下载插件时，记得看一下 Release 说明。这里可能会先写入新功能，旧版 JAR 里不一定有。如果配置项或命令对不上，先确认插件版本和运行平台。

如果有写错、漏写或说得不清楚的地方，可以到 文档仓库 提 Issue。插件本身的问题请发到上面对应的项目仓库，带上插件版本、运行平台和报错日志，方便排查。
