# 关于文档

这里放的是我几个 Minecraft 插件的使用说明：ShitBot、BiliMusicBridge，以及 AllMusic 的 QQ 音乐和酷狗音乐源。装哪个插件，就从对应的安装页开始看。配置、命令和常见问题也都放在各自的目录里。

## 项目地址

| 项目 | 仓库 |
| --- | --- |
| ShitBot | [hutuyee/ShitBot](https://github.com/hutuyee/ShitBot) |
| BiliMusicBridge | [hutuyee/BiliMusicBridge](https://github.com/hutuyee/BiliMusicBridge) |
| QQMusic 音乐源 | [hutuyee/AllMusic_QQMusic](https://github.com/hutuyee/AllMusic_QQMusic) |
| Kugou 音乐源 | [hutuyee/AllMusic_Kugou](https://github.com/hutuyee/AllMusic_Kugou) |

直播点歌和音乐源需要配合 [Coloryr 的 AllMusic](https://github.com/Coloryr/AllMusic) 使用，安装前记得确认版本是否匹配。

## 文档与版本

下载插件时，记得看一下 Release 说明。这里可能会先写入新功能，旧版 JAR 里不一定有。如果配置项或命令对不上，先确认插件版本和运行平台。

## 发现问题

如果有写错、漏写或说得不清楚的地方，可以到 [文档仓库](https://github.com/hutuyee/hutuyee.github.io) 提 Issue。插件本身的问题请发到上面对应的项目仓库，带上插件版本、运行平台和报错日志，方便排查。
