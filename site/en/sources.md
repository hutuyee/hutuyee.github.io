# About these docs

These are guides for my Minecraft plugins: ShitBot, BiliMusicBridge, and the QQ Music and Kugou sources for AllMusic. Start with the installation page for the plugin you want. Configuration, commands, and troubleshooting are in each project's section.

## Project repositories

| Project | Repository |
| --- | --- |
| ShitBot | [hutuyee/ShitBot](https://github.com/hutuyee/ShitBot) |
| BiliMusicBridge | [hutuyee/BiliMusicBridge](https://github.com/hutuyee/BiliMusicBridge) |
| QQMusic source | [hutuyee/AllMusic_QQMusic](https://github.com/hutuyee/AllMusic_QQMusic) |
| Kugou source | [hutuyee/AllMusic_Kugou](https://github.com/hutuyee/AllMusic_Kugou) |

Live song requests and music sources work with [Coloryr's AllMusic](https://github.com/Coloryr/AllMusic). Check version compatibility before installing.

## Documentation and versions

Read the release notes when downloading a plugin. These docs may describe new features before they are available in older JARs. If a setting or command does not match, check the plugin version and platform first.

## Report a problem

For mistakes, omissions, or unclear explanations, open an issue in the [documentation repository](https://github.com/hutuyee/hutuyee.github.io). Report plugin problems in the corresponding project repository above, including the plugin version, platform, and error logs.
